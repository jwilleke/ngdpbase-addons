# Using Association

This page ships with the __association__ addon and is seeded into [{$applicationname}]
when the addon is enabled.

The association add-on holds a unit owners association's own rules, on top of the
__accommodation__ add-on, which keeps the units and who owns and lives in them. It
needs accommodation enabled too.

## Enable the addon

```json
{
  "ngdpbase.addons.accommodation.enabled": true,
  "ngdpbase.addons.association.enabled": true
}
```

Discovery alone does not enable an addon — the keys above are required.
