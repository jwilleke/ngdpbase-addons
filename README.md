# ngdpbase-addons

General-purpose add-ons for [ngdpbase](https://github.com/jwilleke/ngdpbase), each independent of the
others and of any one site.

## Add-ons

| Add-on | Status | What it does |
|---|---|---|
| [condo](addons/condo/README.md) | in development | A condominium's units, keyed by parcel, and their owners |
| request-response | brainstorming | Requests with responses, statuses, owners and hand-offs: maintenance requests, board approvals, expense reimbursements, contact inquiries |
